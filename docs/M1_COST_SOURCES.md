## Access and price limitations

The original CQ-DL article, exact Silicontra module, a fully measured UV-5R AM revision and any full-band qualified modern VHF derivative were **not obtained**. Some Mouser detailed pages return browser cache errors despite searchable price extracts. Mini-Circuits PDF direct opens failed while indexed primary data was available. Onsemi direct PDF returned 403. The final HTTP link report tests reachability, not price/content validity, and may differ from browser indexing. Failed access is recorded rather than filled with invented measurements/prices.

All future orders require a fresh live basket including stock/spares, packing multiples, taxes/shipping and substitution/lifecycle audit. No contact with authors/suppliers or purchase was made.
