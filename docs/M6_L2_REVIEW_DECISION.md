# M6-L2 review decision

**GO for five controlled bare M6-L2 controller evaluation boards.** This is the implementation's engineering recommendation and a candidate for independent review. It is not an order authorization, acceptance tag, production release or permission to energize hardware. Independent review remains required before acceptance or pushing the candidate to public main. M6-L1 remains the previous independently reviewed baseline.

| Gate | Engineering result and evidence |
|---|---|
| A — ESP32 | PASS: exact ESP32-S3-WROOM-1U-N4 / C2980296, no PSRAM. Separate manufacturer drawings match all 40 perimeter contacts and nine paste windows each; exposed land is the documented 3.7 mm square. All GPIO functions remain, including 35–37 and recovery 43/44. The 5 mm antenna tool radius is unobstructed on the controller. |
| B — FoxPro hardware | PASS, calculated: physically exclusive UART links, grounded-source open-drain MOS transmitter, hardware SAFE inhibit, inverted insulated-gate receiver, passive input/off-state limiting, protected return and port TVS. No battery/power rail is exported. Battery reporting is unavailable for both 2S and 4S. Physical fault/ESD qualification remains Gate G. |
| C — Protocol | PASS, host: C11 encoder/decoder, independent timed peer and identify/FoxID/load/verify/clone/CW/status workflows. All 29 FoxPro tests plus 46 inherited host tests and the strict original C11 fixture pass. Coherent RTC snapshots, bounded configuration and native safety hooks are covered. Genuine FoxPro and target timing remain NOT_RUN. |
| D — Expansion | PASS: TCA9534APWR at 0x38, buffered RTC-side bus, reverse blocking and eight individually limited ports; 10 mA header supply budget. POR ports are inputs. GPIO3/46 service links are open; GPIO45 remains NC under the permitted access limitation. Warm MCU reset does not reset the expander; initialization restores inputs and retained UI states cannot enable RF. |
| E — Original architecture | PASS: all 36 RF connector assignments, historical pad functions/geometry, required GPIOs, original protection/power/ground/reset/RF copper and LoRa geometry preserved. Only enumerated digital routes are locally replaced. 4,096 enable combinations, 38 inherited critical package maps, baseline electrical/USB/protection/RF/DFM regressions and 32 new native mutations pass. All 1,869 frozen RF/historical-review files match M7. |
| F — Manufacturing | PASS: KiCad 10.0.6 ERC 0 violations; DRC 0 errors/0 warnings; unrouted 0; parity 0; no DRC exclusions. Standard-JLCPCB native-geometry DFM passes. Board remains 100 × 100 mm, two layers, standard FR4, 1.6 mm, 1 oz, green mask, white legend, lead-free HASL and ordinary through-vias. Fresh Gerbers, separate PTH/NPTH drills, full top stencil and revision-specific ZIP are present. |
| G — Physical | **NOT_RUN.** Not a prerequisite for controlled bare evaluation-board manufacture. Mandatory before assembled RF operation. |

The [review package](../hardware/controller/review/M6-L2/README.md) links native sources, manufacturer matrices, electrical calculations, all 48 populations, costs/MOQ evidence, actual test logs, CAD/DFM reports, fresh schematic/PCB/3D views, fabrication contents, hashes and reproduction commands. All original RF boards and historical reviews remain unchanged.

Implementation limits are explicit: target RTC/scheduler/configuration hooks and an IRAM-safe transport require application integration; this foundation is not complete contest firmware. Oscillator calibration is unsupported, tests are limited to 30 seconds and delegate native arm/rearm/protection authorization, and identical concurrent open-drain frames cannot be distinguished. Native configuration retains features absent from the legacy format. Legacy voltage display is unavailable rather than falsely calibrated.

Physical work still required includes ESP32 USB/boot/recovery and brownout tests; antenna mating, strain relief, RF-board carrier/enclosure fit and Wi-Fi/LoRa coexistence; genuine FoxPro workflows and cable continuity; 2S/4S/USB-only/missing-pack sequencing; powered/unpowered endpoint and contact-fault voltage/current/leakage measurements; expansion input/output/short/disconnect and strap behavior; RTC timing under load; and staged RF/thermal integration. Transient/temperature and CAD spacing scenarios are calculations, not measurements or IEC certification.

No fabrication upload, board order, purchase, hardware energizing, main-branch push, acceptance tag or production release has occurred in this milestone.
