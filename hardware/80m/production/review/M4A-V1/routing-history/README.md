# Intermediate CAD routing history

These records document temporary routing gaps, attempted routes, early ground
fanout and local clearance corrections. They are **not final check results**.
Final authority: native RF80_V1 PCB, DRC.json (0/0/0), XML/netlist,
ground-connectivity.json and fabrication-audit.json in the parent directory.
No intermediate result is a physical measurement. CAD mutation tools are not
verification commands and must not be rerun on the reviewed PCB casually.
