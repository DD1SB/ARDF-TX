# Reproduce RF80-V1R1 review

Run from the repository root with installed KiCad **10.0.6**, its Python bindings and standard libraries/models. Use `/usr/bin/python3`, not a Python environment without `pcbnew`. No network or supplier upload is part of the checks. Verification reads frozen E2/M4A/controller/RF2M sources and writes **only the new review directory**.

The checked-in native candidate is the input. Do **not** run `m4a_design.py --derive/--place`, `m4a_v1r1_apply.py`, old routing scripts or old exporters directly: those are construction/history tools, not current verification. The wrapper adapts the frozen engines to the new output path and explicitly audits only the authorized PTH/artwork deltas.

```sh
kicad-cli version
/usr/bin/python3 tools/m4a_v1r1.py exports
DISPLAY=:97 LIBGL_ALWAYS_SOFTWARE=1 /usr/bin/python3 tools/m4a_v1r1.py exports --only-render
/usr/bin/python3 tools/m4a_v1r1.py verify --logic
/usr/bin/python3 tools/m4a_v1r1.py artifacts
/usr/bin/python3 tools/m4a_v1r1.py geometry
/usr/bin/python3 tools/m4a_v1r1_fit.py
/usr/bin/python3 tools/m4a_v1r1_dfm.py
/usr/bin/python3 tools/m4a_v1r1_interfaces.py
/usr/bin/python3 tools/m4a_v1r1_views.py
/usr/bin/python3 tools/m4a_v1r1_bom.py
/usr/bin/python3 tools/m4a_v1r1_package.py
/usr/bin/python3 tools/m4a_v1r1.py documents
/usr/bin/python3 tools/m4a_v1r1_final_audit.py
/usr/bin/python3 tools/m4a_v1r1.py manifest
```

`DISPLAY` must name an available local display/Xvfb for real KiCad rendering. If :97 is unavailable, start an authorized local X server or select another existing display. A renderer failure is not a passing 3D review. No fabricated preview substitutes for KiCad renders.

The exports log records actual `kicad-cli` commands, return codes and tool diagnostics. Fresh PDFs, copper/assembly views, Gerbers, separate PTH/NPTH, drill maps, placements and IPC follow the native candidate. Native zone refill precedes all geometry/hash checks. Full render includes DNP information; use population.csv and Fox placement for FOX_ONLY.

The final audit checks current hashes, source immutability, archive contents, native/IPC net membership and all required test results. `manifest` runs last to inventory final artifacts and source hashes. To verify the review-file hashes:

```sh
cd hardware/80m/production/review/M4A-V1R1
sha256sum -c SHA256SUMS
```

Absolute paths, execution timestamps, UUID serialization and raster render details can differ between environments. The manufacturing ZIP is deterministic for identical layer/drill inputs; native geometry, net membership, holes and process selections are the acceptance comparisons. No commercial price or physical PASS can be regenerated by CAD scripts.
