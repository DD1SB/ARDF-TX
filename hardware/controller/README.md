# ARDF-TX universal controller — M6-L2 candidate

Active KiCad 10 sources are CTRL.kicad_pro, CTRL.kicad_sch, its referenced sheets and CTRL.kicad_pcb, with local ARDF_CTL libraries. M6-L2 selects ESP32-S3-WROOM-1U-N4 (4 MB flash, no PSRAM), adds optional FoxPro2 compatibility and an optional TCA9534APWR eight-line GPIO interface. See the [review package](review/M6-L2/README.md), [decision](../../docs/M6_L2_REVIEW_DECISION.md) and [reproduction commands](review/M6-L2/REPRODUCE.md).

[M6-L1](review/M6-L1/README.md) remains the previous independently reviewed baseline. Its NO_LORA, LORA_433 and LORA_868 options, module footprint and RF feed remain. RF80/RF2M sources and historical review packages are immutable. All existing GPIO functions, protected battery ID, USB/reset/RTC facilities, RF branch isolation, static controls and fail-off architecture are retained. PACK_ID_FRONTEND_REV2 calibration and the external 10k/22k identities remain mandatory.

The default build retains recovery UART routing and omits both new interfaces. FoxPro population replaces the recovery links with physically separate routing links; never fit both sets. The ESP32's 2.4 GHz antenna is separate from LoRa. Legacy FoxPro battery display is unavailable on both 2S and 4S. GPIO3/46 service links remain open; GPIO45 remains NC without breakout. Select one of the 48 explicit RF/LoRa/interface populations and use its assembly/placement files. An SX1262 response cannot identify its RF band; unknown LoRa disables LoRa TX while otherwise valid autonomous operation remains available.

Independent review and [fresh final reproduction](../../docs/M6_L2_FINAL_REPRODUCTION.md) support GO for five controlled bare evaluation boards. The verified revision is authorized for normal GitHub publication. All physical ESP32/USB/recovery, genuine FoxPro, antenna/coexistence, accessory, fault, power-sequencing and RF/thermal qualification is NOT_RUN. Host foundations are not complete contest firmware. No supplier upload, order, purchase, hardware energizing, acceptance tag or production release is authorized.
