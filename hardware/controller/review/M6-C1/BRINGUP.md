# M6-C1 controlled first-controller acceptance — NOT_RUN

All stages require separate authorization before physical work. Use one controller and one RF module initially. Keep RF-board PA power disconnected and retain its own existing staged bring-up procedure. Do not infer RF performance from controller tests.

1. **Unpowered inspection.** Match exact MPNs/markings to BOM, diode cathodes and MCU/RTC pin1; inspect hidden-ground soldering and USB joints. Check J1/IDC pin numbers with a meter and cable detached. Check all three IDC returns per module. Verify primary-cell holder polarity and absence of any charge path. Leave LoRa DNP. Inspect USB shield/locator and header fit before soldering the first lot.
2. **Controller supply only.** Use a bounded current-limited bench supply, initially6V, then8.4/12/16.8V. Log3.3V, VIN_SYS, pack ADC, input current and device temperature. Exercise reset/STOP/BOOT, slow ramps and brownout. RF connector rails and ARM/MUTE/PREPARE remain inactive before explicit initialization. Check load steps up to the reserved budget, output ripple and rail contract limits at the connector.
3. **USB isolation.** Use a protected USB fixture. Verify flashing/recovery, CC wiring/current, USB-only startup and VBUS sense. With pack voltage present and USB absent, measure USB_LIMIT clamp, USB_VBUS discharge and connector backfeed over temperature; qualify the leakage-clamp estimate before fitting RF modules. Plug/unplug USB during reset and battery operation; no RF permission may arise. Scope USB full-speed data/PHY attach behavior. Do not conduct unqualified supply faults from a Li-ion battery.
4. **RTC and firmware contract.** Program RV3032 backup/charger bits and read back. Set UTC with a measured reference, test POR/invalid dates and remove main supply with a fresh primary cell installed. Log24h temperature/aging drift rather than assuming datasheet values prove system timing. Invalid RTC or clock correction across a slot boundary must inhibit/disarm; no extended slot.
5. **Logic-only RF interfaces.** With RF raw packs disconnected, fit a continuity/logic fixture and load the hardware-test firmware. Exercise every output and ADC; confirm exact SCL/SDA/header mapping, default-off and one-bank behavior. Test absent/unpowered modules, stuck buses and reset while armed. Application progress must stop when its main loop is stalled even if timers/USB/LoRa continue. Verify autonomous RF-board watchdog shutdown and its real timing using the existing RF acceptance procedure.
6. **One RF board on dummy load.** Only after its own power-only gates pass, use the correct common identified pack population and existing RF commissioning procedure. Confirm PREPARE versus PA_PREPARE, SLOT versus KEY, arm quiet/settling, local fault semantics, frequency readback, PWM reconstruction and calibrated level. Test transmitter silence for all faults, unsupported frequencies and cable disconnection. Controller tests do not replace RF power/PEP/AM/spectrum/thermal acceptance.
7. **Fleet/optional operation.** Add the second module only after single-module acceptance, using compatible populations on one common pack; conflicting requests must refuse activation. Test autonomous no-LoRa operation. Populate LoRa only after resolving the exact module identity/land pattern, then qualify radio detection/loss and RF coexistence. Log real transmit/idle energy over Classic/Sprint/Fox/beacon profiles and12h/24h targets. Enclosure, antenna ERP and field performance remain separate gates.

Record instruments, serial numbers, firmware/calibration revisions, ambient temperature, waveforms and pass/fail thresholds. Any fault requires deliberate revalidation and rearming; no automatic restart after reset, heartbeat restoration or remote-link recovery.

Local controls: SW1=BOOT/download, SW2=RESET, SW3=START_N software request, SW4=STOP holding MCU_EN low. Hold STOP to inhibit physically; START never bypasses validation. D30/D31 indicate commanded arm/fault state, not measured RF. Use the assembly drawings and pad numbers when fitting switches; generic package appearance is not a polarity test.

At Stage2, measure each RF connector at150 mA logic load with the intended cable and only that bank powered. Require3.135–3.465 V and less than5 mV additional ground-reference offset under the documented0.40 A host budget; fail before RF activation if these limits are missed. Inspect nylon M3 supports and trimmed underside leads before applying power.
