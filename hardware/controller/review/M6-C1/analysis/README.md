# Construction evidence, not fabrication data

These are intermediate offline DSN/SES routing inputs and sessions for the one controller PCB. They precede final local USB, fuse, switch, ground and width corrections. Do not import them as the current board. Optional parallel-feed route trials that reported no path were on an already-connected net; they do not indicate a final airwire. The final KiCad DRC and native PCB are authoritative. The hot-resistance issue was corrected with TPS22918 devices and their actual larger landings.

No separate controller or RF test PCB is proposed. Only the final fabrication directory is a proposed review dataset.
